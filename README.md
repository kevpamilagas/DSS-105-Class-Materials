# DSS-105 Class Materials

Course materials for **DSS-105: Data Science with Python**, taught at the Air Force Institute of Technology (AFIT).

## Course Structure

| Block | Topic |
|---|---|
| Block 1 | Getting Started with Python |
| Block 2 | Numbers and Data Structures |
| Block 3 | Functions and Classes |
| Block 4 | Arrays and NumPy Basics |
| Block 5 | Pandas and Data Files |
| Block 6 | Pivot Tables in Python |
| Block 7 | Visualization in Python |
| Block 8 | Regression Modeling |
| Block 9 | Generative AI |

Blocks 1–8 each contain a student notebook (empty, for following along in class) and a corresponding exercise for independent practice. Block 9 is the capstone: a guided prompt notebook in which students recreate the Block 5–8 workflow using GenAI.mil, paired with the cleaned dataset and a data dictionary.

## Getting Started

### Primary: Stitches

All coursework is completed on **stitches.mil**, the cloud-based Jupyter notebook environment provided for this course. No local installation is required — just log in and navigate to your course materials.

### Backup: MyBinder

If stitches.mil is unavailable, you can launch a temporary Jupyter environment using MyBinder:

[![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/kevpamilagas/DSS-105-Class-Materials/main)

> **Note:** MyBinder sessions are temporary — any work you do will not be saved once the session ends. Download your notebooks before closing the browser.

## Requirements

The following Python packages are used throughout the course:

- `numpy` — numerical computing and arrays
- `pandas` — data manipulation and analysis
- `matplotlib` — plotting and visualization
- `seaborn` — statistical visualization
- `scipy` — scientific computing
- `statsmodels` — statistical modeling
- `openpyxl` — Excel file support

These are pre-installed on stitches.mil and are automatically installed when using MyBinder.
